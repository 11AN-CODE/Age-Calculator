# 🎂 Age Calculator
A simple, interactive web application built with HTML, CSS, and JavaScript that accurately calculates a person's current age based on their date of birth.

## ✨ Features
Accurate Calculation: Calculates age in years, months, and days.

Intuitive Interface: Clean, user-friendly design using CSS.

Date Validation: Ensures users input a valid date of birth.

Real-time Updates: Uses JavaScript to dynamically display the result.

## 🚀 Getting Started
Follow these steps to get a copy of the project up and running on your local machine.

Prerequisites
You only need a modern web browser (like Chrome, Firefox, Safari, or Edge) to run this application.


Installation
Clone the repository:

Bash

git clone https://github.com/YourUsername/age-calculator.git
Navigate to the project directory:

Bash

cd age-calculator
Open the file: Simply open the index.html file in your preferred web browser.
